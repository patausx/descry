# BUGS — найденное в descry (2026-08)

## B1. РАССИНХРОН АРАНЖИРОВКИ в 4 из 5 демо-генераторов — ПОДТВЕРЖДЁН ЗАМЕРОМ

**Тяжесть: высокая.** Ломает все существующие демо-треки. Данные, не код.

Каждый трек идёт по song-сетке независимо: чейн кончился → `next_song_row()` для этого трека.
Значит в одной song-строке чейны разной длины = треки уезжают в разное время.

`gen_phonk.cpp`: чейн 0 (кик) = 1 фраза, чейн 1 (808) = 4 фразы. Замер `song_row` по секундам:

```
t= 1s rows:   0   0   0   0   0   0   0   0
t= 6s rows:   3   1   0   3   3   3   3   3   <- трек1 на строке 1, остальные на 3
t=11s rows:   0   2   1   0   0   3   0   0   <- кик обернулся, бас ещё в интро
```

К 11-й секунде кик играет строку 0, бас — строку 2, пэд — строку 3. Аранжировка (интро → добавили кик → добавили снейр → брейкдаун) полностью разваливается: слушатель слышит кашу из случайных секций.

Затронуты: `gen_phonk` (чейны 1/4/4/1/1/4), `gen_trap` (1/1/4/4/4/1/4), `gen_demo_track` (4/4/1/4/1/1/4/1), `gen_ambient` (4/4/3/1/1). Чистый только `gen_moonlight` (все по 4).

**Фикс:** в пределах song-строки все чейны одинаковой длины в фразах. Короткий паттерн повторить (`{1,1,1,1}` вместо `{1}`), а не оставлять одну фразу.

## B3. `.tr3d` не содержит аудио — сэмплерные демо молча немые

`SamplerParams.sample_slot` — индекс в глобальный `SampleBank`, наполняемый отдельными `sample_XX.s16`.
Проект с сэмплерным инструментом, приехавший без `.s16`, играет тишину на этих треках **без единого предупреждения**.
Прямо влияет на возврат демо-пака в релиз: класть только `.tr3d` недостаточно.
**Фикс:** демо-пак = `project_XX.tr3d` + все нужные `sample_XX.s16` + `.name`.

## B4. нумерация слотов разъезжается: проекты hex, сэмплы dec

```
project_%02X.tr3d   // 00..0F ШЕСТНАДЦАТЕРИЧНО
sample_%02d.s16     // 00..63 ДЕСЯТИЧНО
```
В одной директории. Для слотов 0..9 совпадает, дальше — грабли: слот 10 это `project_0A.tr3d`, но `sample_10.s16`.
Не баг движка (обе стороны последовательны), но гарантированная ловушка для скриптов и для человека. Задокументировано в `docs/ENGINE_NOTES.md`.

## B5. мелочь: `Song::dly_time` в UI-единицах

`dly_time = 200` это «*32 фрейма» ≈ 200 мс при 32 кГц. Совпадение числа с миллисекундами — случайность, при другом SR развалится. Ловушка при чтении кода.
